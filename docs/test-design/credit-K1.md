## 3. Техники

Для каждого поля — **классы эквивалентности** (допустимые / недопустимые) и **границы**. Пример для «Сумма»:

| Класс | Значения | Ожидание |
|---|---|---|
| допустимые | 0,01; 1 200 000; 99 999 999,99 | принято |
| недопустимые: ≤ 0 | 0; −1 | сообщение у поля |
| недопустимые: больше 2 знаков | 100,555 | сообщение у поля |
| недопустимые: не число | «много», пусто | сообщение у поля |
| граница | 0 / 0,01 | отказ / принято |

Сделай такие же таблицы для: **Ставка**, **Срок**, **Платёж**, **Дата выдачи**.
Подумай про даты: выдача **31-го** (в феврале нет 31-го — когда платёж?), выдача **29.02**, выдача в **праздник**.
